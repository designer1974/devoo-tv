# Devoo TV 📺

Canali TV gratuiti per bambini e di tutto il mondo, con il PIN per i genitori.

- **Kids** (si apre sempre qui): solo canali per bambini, filtri per paese, preferiti
- **🌍 Mondo** (solo con il PIN): canali per paese e per categoria
- Dopo 3 PIN sbagliati bisogna aspettare; uscendo dall'app il Mondo si richiude
- Aggiornamenti scaricati e installati dentro l'app

I canali vengono da [iptv-org](https://github.com/iptv-org/iptv), elenco gratuito e aperto di TV che trasmettono pubblicamente.

## Scaricare l'app

Apri la pagina **Releases** dal telefono e scarica `DevooTV.apk`.
